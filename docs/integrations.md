Northline pulls requests in from several channels into the same unified queue:

- **Email** — a dedicated inbox address per queue; replies from agents send back through the same thread.
- **Web forms** — embeddable request forms with custom fields per queue, no code required to set up.
- **Slack** — a `/northline` command lets requesters file a ticket without leaving Slack; agents can reply inline and the thread syncs back to the ticket.
- **API** — full REST API on Business and Enterprise for creating, updating, and querying tickets programmatically; webhooks are available for outbound events (ticket created, status changed, SLA breached).

There is no native Microsoft Teams integration yet — it is on the public roadmap but not scheduled. Customers currently route Teams requests through the web form or a shared email alias instead.
